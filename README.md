# indo food price claim extraction
Extracting food price claims and causes of scarcity from Indonesian text using weak supervision, commodity normalization, and verification against official price data.
Ekstraksi Klaim Harga dan Penyebab Kelangkaan Pangan dari Teks Berbahasa Indonesia

Project Akhir Pemrosesan Teks, Semester Gasal 2026/2027, Kelas 2025E.

Status: tahap ide project. Kode crawling, labeling function, pemodelan, verifikasi, dan dashboard akan ditambahkan bertahap.
